# Introduction
Create apps a real .exe without a line of code!

# Step by Step
### 1. Open editor
To open, you just need to simply click in this link: https://nbc-nu.github.io/AppStudio/
### 2. Create
Wait the program start. Don´t forget to allow pop-ups because when it starts, will show
a pop-up asking you the app name, put your app name and do not leave it blank, then use
the blocks to program.
### Important to know
Remeimber that you need to put the OnStart block, its important to start at least your program.
### 3. Donwload
Press space and wait it compile. Then extract the zip donwloaded and when open the .exe, windows
probabilly will show smartscreen blocking it, so you can select See More and then Open Anyway.
### About the SmartScreen Screen
This program is not a malware, its just because the donwloaded .exe do not have a certificate.
